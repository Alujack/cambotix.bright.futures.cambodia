HOW TO ADD A PHOTO TO THE HOME PAGE SLIDESHOW

1. Put the photo in this folder (jpg, jpeg, png, or webp).
2. Name it with a number first, then a short description, using dashes:
      06-children-learning-english.jpg
   The number sets the order. The words become the photo caption
   for screen readers ("Children learning english").
3. That is all. The slideshow picks up every photo in this folder
   the next time the site is built or the dev server refreshes.

To remove a photo, delete the file. To reorder, rename the numbers.
Keep photos under about 1600 pixels wide so the site stays fast.
